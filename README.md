# LocalHelp

LocalHelp es una aplicación educativa que ayuda a las personas a encontrar recursos comunitarios en su ciudad.

## Categorías
- Alimentación
- Vivienda y refugios
- Salud
- Educación
- Ayuda comunitaria

## Tecnologías
- Python
- Visual Studio Code

## Instalación

Para instalar los paquetes necesarios, ejecuta:

```bash
python -m pip install -r requirements.txt
```

## Limitaciones

La información puede no estar siempre actualizada. Las distancias son aproximadas y algunos servicios pueden tener horarios o disponibilidad diferentes.

## Privacidad

No introduzcas direcciones particulares ni información personal sensible.
